# MoneyDJ 基金分類：淨值距一年高點比較報表

## 做什麼

1. **分類表**：`https://www.moneydj.com/iQuote/iQuoteFundCatFund.djhtm?A=2&B=1&C={C}` 的每一檔基金：
   名稱、日期、一日、一週、一個月、三個月、今年以來、一年、三年、年化標準差。
2. **基金頁**（分類表的基金名稱超連結）：淨值日期、最新淨值、最高淨值(年)（另外也存 每日變化、最低淨值(年)）。
3. **計算**：`距年高 % = (最新淨值 ÷ 最高淨值(年) − 1) × 100`。0 = 正在一年高點，−8 = 比一年最高淨值低 8%。
4. **輸出**：單檔自含 HTML 報表 + `funds.csv`（Excel 可直接開）+ `summary.json`。

## Python 環境

腳本只用標準函式庫，**任何 Python 3.8+ 都能跑，不用 pip 安裝套件**。執行時設 `PYTHONIOENCODING=utf-8`。

找可用的 Python（依序試，第一個印出 3.8 以上版本的就用它）：

1. 安裝時記下的路徑：skill 資料夾裡的 `python_path.txt`（`install.bat` / `install.sh` 會寫入）。
2. `py -3 --version`（Windows 官方安裝程式附的啟動器）
3. `python3 --version`、`python --version`

Windows 上 `python` 可能是 Microsoft Store 的空殼（執行後沒有版本號或跳出商店），那就不能用，換下一個。

## 步驟

### 1. 執行腳本

`<skill>` = 這個 SKILL.md 所在的資料夾（通常是 `~/.claude/skills/moneydj-fund-nav-high-report`）。

```bash
PYTHONIOENCODING=utf-8 <python> "<skill>/scripts/fund_nav_high_report.py" \
  --category 47 --out <工作資料夾>/report.html
```

| 參數 | 說明 |
|---|---|
| `--category` | 分類頁網址的 `C=` 值。使用者貼網址時從網址取出。47 = 台灣（375 檔，2026-10-02）。其他常用：48 大中華、8 亞洲、1 日本、6 印度、51 中國、31 韓國、53 越南。 |
| `--out` | HTML 輸出路徑；`funds.csv`、`summary.json`、當日快取放同一個資料夾（或用 `--out-dir`）。 |
| `--match` | 只保留名稱含這些字的基金，逗號分隔，例如 `--match 統一,野村,元大`。 |
| `--limit N` | 只跑前 N 檔，測試用。 |
| `--workers` / `--delay` | 平行抓基金頁的數量（預設 4）與每次請求前的等待秒數（預設 0.2）。不要超過 6，對網站客氣一點。 |
| `--no-cache` | 不用當日快取，全部重抓。 |

台灣分類 375 檔約 40 秒。stdout 最後一行是摘要 JSON（基金數、取得淨值數、失敗數、距年高中位數、距年高 1% 內檔數、低於 10% 檔數）。

**執行時間**：MoneyDJ 約 16:30–18:00 更新淨值，這段時間部分基金頁會自相矛盾（陷阱 00）。若現在是這段時間，
先告訴使用者數字可能還在更新、建議 20:00 後重跑；使用者仍要現在跑就照跑，並在回覆中註明產生時間。

### 2. 檢查（不要跳過）

- `n_failed` 應為 0；不是 0 時看 stderr 的 `! 代碼: 錯誤`，通常重跑一次（快取會跳過已成功的）就好。
- `n_with_nav` 比 `n_funds` 少是正常的：新成立的級別或主動式 ETF，基金頁四個淨值欄位都是 `N/A`（見陷阱 3）。
- 抽一檔到基金頁核對：最新淨值、最高淨值(年) 和報表一致，距年高 % 手算一致。
- 使用者要求「驗證資料正確」時，跑完整驗證（在 `funds.csv` 所在資料夾執行）：
  `node <skill>/scripts/verify/browser_check.js 60`，再 `python <skill>/scripts/verify/compare.py`。
  判讀方式見下方「驗證」：日期相同的列應 0 差異；日期不同的列是某一邊拿到舊快取或 MoneyDJ 正在更新。

### 3. 發布

用 Artifact 發布 HTML（範本已符合 artifact 規範：沒有 doctype、顏色全部是 token、支援深淺色）。回覆裡用幾句話說重點：距年高中位數、多少檔在年高 1% 內、離年高最遠的幾檔（通常是單日反向型），並附 CSV 路徑。

## 報表內容

- **摘要列**：基金數、距年高中位數、距年高 1% 內檔數、低於年高 10% 以上檔數。
- **散佈圖**：x = 距一年高點 %，y = 一年報酬 %；紅點 = 距年高 1% 內；每個點是連到 MoneyDJ 基金頁的連結。
- **最接近 / 最遠離一年高點** 各 5 檔。
- **比較表**：14 欄，點欄名排序（再點反向），搜尋名稱或代碼，篩選 全部／1% 內／−1%~−10%／低於 −10%；「隱藏槓桿／反向型」同時套用到表格、圖和清單。
  最後一欄 **「最新淨值與最高淨值差距 %」**（使用者指定的欄名；圖與清單簡稱「距年高」）固定在表格最右側（sticky），
  表格橫向捲動時也一直看得到；附橫條，依程度分色。CSV 用同一個欄名。
- 台股慣例：紅 = 漲、綠 = 跌。缺值顯示 `--`，排序永遠排最後。

## 陷阱（實測確認，2026-10-02）

0. **MoneyDJ 有多台伺服器快取，同一個網址會輪流回傳新舊版本**（最重要）。同一檔基金頁連抓 8 次，
   最多 7 次是前一天的淨值；分類 JSON 的 `ExpireTime` 也會在 17:07／17:11／17:17 之間跳動，舊版落後最多約 30 分鐘。
   腳本的 `fresh()` 在每個請求加上 `&_=<時間戳>`（jQuery `cache:false` 的做法），實測 8/8 都拿到最新版。
   另外基金頁的淨值日期若仍早於分類表日期，`fetch_detail()` 會再抓最多 3 次取最新。**不要拿掉這個參數。**
   瀏覽器開分類頁也可能看到舊版（頁面自己的 JS 沒有加這個參數），所以用瀏覽器核對時，日期不同的列要排除。
00. **MoneyDJ 更新淨值的那段時間（約 16:30–18:00），頁面可能自相矛盾**：例如 2026-10-02 17:09，宏利 3 檔基金頁
   「最高淨值(年)」已經更新（162.13 → 162.78），「最新淨值」還停在前一天的 162.13，差距就暫時顯示 −0.4%。
   這是來源網站的狀態，不是爬錯。要最穩定的數字，在晚上 20:00 後或隔天早上執行；報表上方會顯示產生時間。

1. **分類頁本身沒有資料**。`iQuoteFundCatFund.djhtm` 的表格是頁面載入後由 JS 呼叫
   `/JsonData/iQuote/iQuoteJsonData.xdjjson?x=FundAreaFund&a={C}` 填入的，直接抓 HTML 只會看到「目前查無資料」。
   腳本直接抓這個 JSON（UTF-8），不需要瀏覽器、cookie 或 referer。`V1`=代碼、`V2`=名稱、`V3`=日期、
   `V4..V11` 依序是 一日／一週／一個月／三個月／今年以來／一年／三年／年化標準差、`V12`=地區名稱。
   缺值是空字串 `""`，要當「無資料」，不能當 0（同 `moneydj-fund-house-ranking` 的發現）。
2. **基金名稱超連結的網址依代碼而不同**（照頁面自己的 JS）：代碼 `AC` 開頭（國內基金）→
   `/funddj/ya/yp010000.djhtm?A={code}`；其他（境外基金）→ `/funddj/ya/yp010001.djhtm?A={code}`。
   兩種頁面都是 **Big5** 靜態 HTML（用 cp950 解碼），淨值在同一種表格：表頭列
   `淨值日期／最新淨值／每日變化／最高淨值(年)／最低淨值(年)`，數值在下一個 `<tr>`。
3. **有些基金頁四個淨值欄位都是 `N/A`**（2026-10-02 台灣分類有 16 檔：新級別、I 類型、TISA、主動式 ETF）。
   這不是抓取失敗：腳本記為缺值，報表顯示 `--`，不計入摘要統計。
4. **淨值日期可能和分類表日期不同**（海外或晚一天公布的基金）。報表把不同的淨值日期標成橘色，不要當成錯誤。
5. **快取一天一份**（`detail_cache_YYYYMMDD.json`）。同一天重跑只抓沒成功的；隔天一定重抓，不會用到舊淨值。
6. **單日反向型基金會把距年高拉到 −48% 左右**，散佈圖的 x 軸會被壓縮。報表的「隱藏槓桿／反向型」
   （名稱含 正2、反1、正向、反向、槓桿、2倍、單日）可以排除它們。
7. 在 artifact 裡 `window.open` 對多數檢視者無效，所以散佈圖的點用 SVG `<a href>` 連結，不用 JS 開視窗。
